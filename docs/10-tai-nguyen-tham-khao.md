## 10.2 Học tiếp

| Nguồn | Nội dung |
|---|---|
| **CleverTap University (CTU)** | Truy cập từ dashboard, mục **Need help**. Có các khóa về Segmentation (cơ bản + nâng cao), Journeys, A/B Testing |
| **Chứng chỉ** | Mở khóa học cần chứng chỉ → bấm nút **Certificate** trên thanh khóa học |
| **Release Notes** | Mục *What's New* trong docs — dashboard thay đổi thường xuyên |
| **Events Changelog** | Theo dõi thay đổi về event |

## 10.3 Công cụ hỗ trợ

| Công cụ | Vị trí |
|---|---|
| **Debugger** | Mục Support trong docs — gỡ lỗi tích hợp |
| **Debug Events** | Thêm `?showDebugEvents=true` vào URL trang profile hoặc Find People |

## 10.4 Lộ trình học tiếp theo

```
ĐÃ XONG
  └─ Getting Started with CleverTap  ✅

TIẾP THEO (theo thứ tự ưu tiên)
  ├─ 1. Segmentation (cơ bản → nâng cao)
  │      → kỹ năng dùng nhiều nhất hằng ngày
  │
  ├─ 2. Journeys
  │      → nơi tạo ra giá trị tự động hóa lớn nhất
  │
  ├─ 3. A/B Testing
  │      → để biết cái gì thật sự hiệu quả
  │
  ├─ 4. Hyper Personalization (Liquid tags, Linked Content, Catalogs)
  │      → nâng chất lượng nội dung
  │
  ├─ 5. CleverAI (IntelliChannel, IntelliTime, Predictions)
  │      → tự động hóa quyết định
  │
  └─ 6. Developer track (SDK Android/iOS/Web, Server API, Data Import/Export)
         → nếu cần làm việc sâu với đội kỹ thuật
```

## 10.5 Khái niệm nên tự tìm hiểu thêm

Những thứ chưa có trong khóa Getting Started nhưng sẽ gặp khi làm thật:

| Chủ đề | Vì sao cần |
|---|---|
| **Composite Events** | Ghép nhiều event thành một để phân tích gọn hơn |
| **Lifecycle Optimizer** | Đẩy user qua các giai đoạn vòng đời một cách có hệ thống |
| **Product Experiences / Remote Config** | Đổi hành vi app không cần release store |
| **Promotions (loyalty, rewards)** | Nếu sản phẩm có chương trình tích điểm |
| **Data Import/Export (SFTP, data warehouse)** | Đồng bộ với hệ thống nội bộ |
| **Partner integrations** | Nối với attribution, CDP, CRM, data warehouse |
| **Security & Data Governance** | SSO, 2FA, IP whitelist, audit log |
